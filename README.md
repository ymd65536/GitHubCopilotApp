# たまに機械語でデレる隣のAIさん

自律型運用 × 恋愛シミュレーション

これは GitHub Copilot Canvas 向けに作成した、タイトル画面から始まる軽い恋愛シミュレーションの MVP です。

## 概要

- 32歳の現役エンジニア「マサチカ」が主人公
- AIヒロインとの初対面から物語が始まる
- 好感度、信頼、知識、自律性などの状態を管理
- プレイヤーの選択や対応が関係性に影響する
- 将来の拡張を見据えたシナリオと状態管理を分離した構成

## 主要機能

- タイトル画面
- New Game からの導入演出
- 主人公のモノローグ
- AIヒロインの初登場
- ステータス管理と状態保存
- Copilot アドバイスの導入
- 機械語でデレる仕組みのための拡張ポイント

## 使い方

1. このリポジトリを GitHub Copilot の Canvas 環境に読み込む
2. `tamachine-ai` キャンバスを開く
3. 「New Game」を選択して遊ぶ

## ディレクトリ構成

```text
.github/
  extensions/
    tamachine-ai/
      extension.mjs
README.md
```
